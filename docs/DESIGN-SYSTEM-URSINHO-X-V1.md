# URSINHO X — Design System v1 (sem verde)

## Identidade visual
- Fundo principal: #07090F
- Superfície: #0E121B
- Cartões: #1C2331
- Texto: #F3F5F9
- Texto secundário: #9AA4B5
- Destaque periwinkle: #6E7BFF
- Lilás principal: #8B7BFF
- Lavanda: #B5A0FF
- Azul de apoio: #7DA8FF
- Atenção: #F5B544
- Erro: #F26B6B

## Regra de marca
Verde, menta, esmeralda e castanho não fazem parte da identidade visual. Os estados positivos são mostrados com lilás/lavanda e ícone/texto de confirmação; avisos usam âmbar e erros usam coral.

## Sistema de layout
- Tipografia: Inter, com fallback de sistema.
- Espaçamentos em escala de 8 px.
- Alvos de toque mínimos de 48 px nas aplicações móveis.
- Páginas com uma finalidade principal e secções claramente delimitadas.
- Cartões com contraste discreto, linhas lilás/cinza e sombras moderadas.
- Respeitar `prefers-reduced-motion`.

## Movimento
- Animações curtas de entrada e respiração suave nos elementos de marca.
- Movimento nunca representa conectividade, pagamento ou conclusão de operação.
- Estados operacionais devem vir exclusivamente do Backend.
